# Booki

A travel accommodation booking website landing page, built as part of the OpenClassrooms Web Developer program.

## Overview

Booki is a responsive landing page for a fictional travel accommodation booking platform. Users can search for accommodations and activities in various cities.

## Features

- Responsive design (mobile, tablet, desktop)
- Search functionality UI
- Accommodation cards with ratings
- Activity listings
- Filter options

## Technologies

- HTML5
- CSS3 (Flexbox, Grid)
- Font Awesome icons

## Preview

The site adapts to three breakpoints:
- Mobile: < 768px
- Tablet: 768px - 1024px
- Desktop: > 1024px

## Getting Started

1. Clone the repository
```bash
git clone https://github.com/karimLamari/booki.git
```

2. Open `index.html` in your browser
